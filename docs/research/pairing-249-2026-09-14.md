# Pair a remote QR qualification, 14 September 2026

Issue [#249](https://github.com/avoid-quest/couch/issues/249) adds the existing Connections QR to the native Pair a remote shortcut. The change starts from `origin/main` at `f60f3daea2dd9e11c2ed483ce094866ec8d0ce8c`. No appliance deployment, pairing mutation or physical test ran for this change. GitHub Actions remains paused.

The dialog requests the current six-digit code through the existing authenticated endpoint and encodes the first advertised Couch address with `#pair=CODE`. Manual addresses and the TV code remain visible. A disconnected session removes the QR; reconnecting or reopening fetches it again. Loading and request failure never show an address-only QR. Retry and a visible Close remain available. The phone form explains stale-code and connection recovery without clearing the guest's device name.

Pairing still uses `/api/pair`. No authority, database, migration, token storage or administrator-claim behavior changes.
