# Host on my computer, control from anything

Status: preview · Scenes: home, group, coworking

Any computer with the Couch app can be the Couch. Every phone, laptop or other
Couch app can control it, and the same app can join another Couch instead.

## Journey

1. First launch: **Where is your Couch?** → **Host on this computer** → **Name
   this computer** → **Share it on your network?** → **Share** → **Done**.
2. Phones and laptops pair ([Join a Couch](join-a-couch.md)) and control it.
3. To join a different Couch: the Couch's name in the header, or **Settings →
   General → Connection** → **Another Couch** → **Connect**; **This computer**
   hosts again.
4. On a computer: **?** lists the **Keyboard shortcuts**; media keys and the
   system's media controls work too.
5. Closing the window keeps Couch hosting; **Quit Couch** stops it.

## Done when

- The Mac, Windows and Linux apps can host, or join another Couch on the
  network.
- A browser, a phone or another Couch app controls everything its rights allow.
- Keyboard and system media controls follow the same rights.
