# Keep everything up to date

Status: preview · Scenes: admin

From my phone, I keep the Couch, its media tools and every Couch app in the
house up to date, without walking to each device.

## Journey

1. **Settings → Updates → Check for updates**.
2. The page lists each Couch app (the Couch computer, the TV, desktops) and the
   **Media tools** (yt-dlp, FFmpeg, QuickJS, mpv).
3. **What's new** shows a ready update's release notes.
4. **Update <name>** or **Update N devices**; if something is playing, **Stop
   playback and update**.
5. Each app can follow **Stable** or **Preview**.

## Done when

- One page updates the Couch, its media tools and connected apps, in a safe
  order.
- Nothing playing is interrupted without asking.
- An app that fails to start after updating goes back to the previous version.

## Demo

Needs: an installed Couch on the previous preview and a phone.

## Known issues

- Browsers and phones aren't update targets; they load the Couch's page.
- Stable has no release yet.
