# Turn a computer into the TV

Status: preview

Lorenzo plugs a small computer into the TV, turns on **TV mode** and taps
**Restart Couch**. From the sofa he gets around with the remote's arrows,
**OK** and **Back**, tries a display in **Screen** and taps **Keep**, and plays
a **Test tone** through the soundbar. His phone's **Remote** does the same.

## Good to know

- **Output**, **Test tone** and Bluetooth speakers work on Linux. On a Mac or
  Windows computer, set up speakers in the system.
- Couch starts with the computer only when it was set up with the Debian
  appliance install ([native TV](../native-tv.md)).
