## Recovery limits

The restored cache came from the earlier canceled run, before any completed AppImage existed. This run made no replacement cache because its key matched exactly. The provider shutdown hook removed the build container and retained only the base builder image; it then reported no active SSH sessions and shut the runner down immediately. The exact signed candidate is therefore unavailable through the configured artifact, dependency-cache and container-cache paths.

[Blacksmith SSH access](https://docs.blacksmith.sh/blacksmith-observability/ssh-access) is available only while the job runs. Its short post-job grace period applies to a session already connected, which this run did not have. [Testboxes](https://docs.blacksmith.sh/blacksmith-testbox/overview) dispatch new workflow environments; they are not a documented restore of a finished job's workspace. No supported recovery of this run's completed candidate was identified. No new job or access setting was created during this investigation.
